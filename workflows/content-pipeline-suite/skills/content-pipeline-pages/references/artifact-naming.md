# Artifact naming

Campaign root: `{campaign_dir}/06-content-pipeline/pages/`

| Stage | File |
|-------|------|
| brief | `p.1-brief/page-{slug}-brief.md` |
| draft | `p.2-draft/page-{slug}-draft.md` |
| edit | `p.3-edit/page-{slug}-edit.md` |
| polish | `p.4-polish/page-{slug}-polish/page-{slug}-polish.md` |

One slug per invoke. Do not write `03-write/`, `04-publish/`, or `05-archives/`.
