# ContentMaxima — Examples

## Single modules

**Keyword matrix:**
```
You: "generate a content maxima matrix for press releases"
```
→ Matrix workflow → `matrix_report.xlsx` (or similar) with semantic matrix + algorithm trigger words.

**Audience personas:**
```
You: "generate content maxima personas for SEO tools"
```
→ Personas → audience segments and content preferences.

**Content pathways:**
```
You: "generate content maxima pathways for Press Advantage as a marketing manager"
```
→ Pathways with entity + persona → `.pdf`.

**Linguistic signatures:**
```
You: "generate content maxima signatures for Authority Beacon"
```
→ Signatures → `.pdf` with linguistic patterns.

**Perspectives by category:**
```
You: "generate content maxima perspectives for link building"
```
→ Perspectives → `.xlsx` with category angles.

**NLP analysis with related terms:**
```
You: "run content maxima analysis for press release distribution with 8 related terms"
```
→ Analysis with `--related 8` → `.xlsx`.

## Full training run

```
You: "run content maxima train AI for local SEO"
```
→ TrainAI → all 6 module outputs (10–20 minutes possible). Best when starting a new content initiative.

## Reverse-engineered matrix

```
You: "build a reverse-engineered content maxima matrix for local SEO agencies"
```
→ `full-matrix-run.ts` → CSV/JSON (needs `OPENAI_API_KEY`, no Content Maxima login).
