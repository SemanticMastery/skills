6. Owner Interview — the repair loop

Init Photos Run Pages init Pages Interview Stories

Not a step in a line. This is what you run when the page evidence gate says block. A blocked page is not a prompting problem — it means nobody has told you how this business actually delivers the service, so there is nothing honest to write.

Where it enters
Trigger

pd-coverage: block

Too many grid rows are Unknown, Unverified, or in Conflict. No run row is created. The message names this skill and the scope slug.

→
01

Gaps

Typed gap list per offering or company-wide, pulled from product documentation, briefs, crawl, and any live-page text you paste in.

→
02

Pack

You draft the wording from the gaps plus the industry seed. The script validates, caps, orders, and renders a JSON + Markdown pair.

→
03 · you

Interview

Call, filled pack, chat, or your own hosted voice agent. Asked in pack order. No invented questions, no paraphrasing toward specificity.

04 · you

Record

You confirm the note-to-question mapping before a single answer is written. Unmapped notes are kept but never compiled.

→
05

Compile plan

A tagged refresh diff. This skill stops here — it does not write product documentation itself.

→
06 · you

PD refresh

product-documentation owns the overwrite and the source precedence. You confirm before it lands. The record gets a PD-SRC id back.

→
07

Re-sync

Init's sync-resources copies the refreshed doc into 01-resources/ so produce reads the new truth.

→
Back

Page passes

Re-run the evidence gate on that slug and continue. The claim now has a citable first-party source.

Why the loop is this strict

Record state machine

open → captured → compiled → superseded. Illegal transitions exit with an error rather than guessing.

No free-text parser

There is deliberately no --from-notes. Automatic note parsing is exactly where invented facts get in.

Seeds ask, never assert

An industry seed suggests questions to ask. It never states a fact about this business.

Waiving is on the record

You may waive a block and write anyway. The waiver is persisted with your name, so it is a decision, not an accident.

The point: turn “we could not verify that” into a sentence the owner actually said, with a source id attached.
Out of scope: visitor copy, self-serve forms, customer research, a second PD writer
