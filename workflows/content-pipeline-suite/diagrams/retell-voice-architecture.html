Deploy in six commands

Deploy

npm install, wrangler login, npm run vendor-sdk, wrangler deploy. No account id is committed, so you cannot deploy into the wrong account by accident.

Secrets

wrangler secret put for the Retell key, a host token you invent, and an optional webhook key.

Agents

Three --apply runs on the same Worker: default, retell/expert, retell/voice. Paste each id into wrangler vars, redeploy.

Verify

--verify diffs live retention against the template and posts a signed self-test. Stale keys fail here, not in front of a client.

Two retention clocks: your host purges at expiry + RETENTION_DAYS; Retell keeps its own copy. Voice links default to 2 days. Pull before the shorter window.
