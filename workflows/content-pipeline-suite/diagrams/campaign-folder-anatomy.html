Manifests — the real source of truth

content-pipeline-init-manifest.json status: init_complete | init_partial awaiting_horizon | awaiting_plan awaiting_taxonomy plan.horizon_weeks, resource classes content-pipeline-run-manifest.json gate_mode, copywriting_model current slot, per-stage status next_action pipeline-pages-manifest.json setup.status: setup_complete page decisions + seeds + matrix paths runs[slug].matrix_terms, pd_coverage library-manifest.json every photo id, status, approved_tags

Stage prose in a CONTEXT.md is the writing instruction. Progress lives in the manifest. After a context reset, the manifest is what tells the agent where it stopped — which is why no skill records progress by editing prose.

Two rules worth memorizing. Resources are copied in, never edited in place — originals stay in 01-intake/. And each campaign owns its own classify.mjs, because one business's “keep this photo” is another's off-topic.

Debugging shortcut: read the manifest before you read the chat history. It knows the truth; the transcript only remembers it.
