# 09 — Glossary

Terms used in this course.

**ai-isms.md** — Banned-language list shipped in the template at `01-resources/ai-isms.md`. Draft, edit, and polish read it. The roadmap step does not.

**Campaign folder** — The brand folder you pass as `campaign_dir`. It contains intake and, after init, `06-content-pipeline/`.

**Companion** — A skill init dispatches for one missing research class. Init does not reimplement that skill.

**Copywriting model** — Where brief, draft, edit, and polish are written. Inherit, a Cursor pin, or an external app. Anthropic is refused.

**Editorial roadmap** — `02-plan/editorial-roadmap.md`. One row is one slot. 13 weeks is 39 posts. 26 weeks is 78 posts. Init writes it.

**Fal miss** — Stage 3.5 found no approved photo for the slot and called Fal. An empty library is this, not a failed init.

**Gate mode** — `review` stops after each produce stage. `auto` chains one slot through schema.

**init_complete** — Init manifest status when eight classes, `ai-isms.md`, the roadmap, and the SiteSwarm taxonomy are all present.

**Keyword gate** — Init stop until you supply seed keywords, and a location when PAA is missing.

**Slot** — One roadmap row, produced from 3.1 brief through 3.6 schema in one run invoke.

**Story bank** — `{Company}-story-bank.md` in `01-resources/`, refreshed from an expert-interview series. Optional. Never a run blocker.

**SiteSwarm tag taxonomy** — `02-plan/siteswarm-tag-taxonomy.md`. Allowlist for photo classify and for image matching. Init writes it from roadmap clusters.

**Voice DNA** — A `*voice-dna*` (or brand-voice / author-voice) file in `01-resources/`. `voice-interview` can produce it. Run consumes it before draft. Zero files means a professional default.

**Wave** — Init's three research passes. Wave 1 dossier. Wave 2 crawl, Matrix, Personas, PAA, fanout. Wave 3 product documentation and ICP.
