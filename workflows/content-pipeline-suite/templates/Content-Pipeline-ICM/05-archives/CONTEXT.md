# 05-archives — Stage Context

## Job

Store completed plans, finished produce runs, and retired publish packs off the live pipeline for this campaign copy.

## Inputs

- Completed 13/26-week plans from `02-plan/` (when a run is done)
- Finished piece folders / packs from produce/publish when no longer active

## Process

1. Move or copy completed artifacts here with a clear run label (dates / horizon / campaign).
2. Do not use this folder as the working surface for new planning or drafting.
3. Keep enough metadata to reopen a past run if needed.
4. Do not archive or remove `01-resources/ai-isms.md` from the live resources folder.

## Outputs

- Archived run bundles (plan + selected produce/publish artifacts)
- Short index note of what was archived and when

## Notes

- Keep this stage focused on its one job.
- Point agents here from the root `CONTEXT.md` task table.
- Each campaign duplicate keeps its own archives.
